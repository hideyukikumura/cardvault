# Cardvalia - ご利用ガイド

本アプリは、専用のデータベースを使わず、**お客様のGoogleドライブ**を安全なデータベースおよび画像ストレージとして使用する「完全個人向け名刺管理PWAアプリ」です。

スマホで快適にスワイプ操作でき、アルファベット検索やタグ検索が可能です。日本語・英語のUI切り替えにも対応しています。

---

## ✨ 主な機能

- **名刺の登録・編集**：名前、読み方（アルファベット）、タグ、メモ、登録年月など、登録後もいつでも内容を修正できます。
- **タグ管理**：登録済みのタグから選んで付与できるほか、新しいタグをその場で作成することも可能です。1枚の名刺に複数タグを付けられます。
- **メモ欄**：名刺ごとに自由記述のメモを残せます。
- **登録年月の記録**：名刺を登録した年月を「Aug. 2026」のような形式で自動記録し、後から修正も可能です。
- **日本語 / English UI切り替え**：「設定」画面からUIの表示言語をいつでも切り替えられます（名刺自体のデータは翻訳されません）。
- **オフライン対応（PWA）**：ホーム画面に追加してアプリのように使え、Service Workerが自動的に最新版へ更新します。
- **ミッション**：名刺の登録数やタグ数、合戦・デュエルの成績などに応じて、隠されたミッションが解放されていきます。

---

## 🎌 合戦モード（Showdown Mode）／デュエルモード

登録されている名刺を「タグ」または「名前の頭文字（イニシャル）」でチーム分けし、六角形が並ぶ架空の大陸マップとして表示する「合戦モード」と、ランダムな2枚を1対1で対戦させる「デュエルモード」があります。勝利した名刺にはポイントが加算され、それぞれ独自のランキングを確認できます。

これらは単なる遊び心だけの機能ではなく、**ずいぶん前に名刺交換をして疎遠になってしまった方を、マップやランキングをきっかけに思い出し、いつまでも忘れないようにするための機能**です。懐かしい人を思い出す、ちょっとした脳トレとしてもお使いいただけます。

## 📥 使い方

Cardvaliaはすぐに使えます。事前準備は不要です。

1. アプリのURL（またはPlayストア版）を開きます。
2. 「Googleアカウントでサインイン」をタップします。
3. 初回サインイン時のみ、名刺データの保存先としてご自身のGoogleドライブ内の任意のフォルダを選択します（フォルダ選択ダイアログが表示されます。新しいフォルダをその場で作成することも可能です）。
4. 以降、名刺データ・画像・合戦やデュエルの記録はすべて、選んだフォルダの中にのみ保存されます。開発者側のサーバーには一切送信・保存されません。

保存先フォルダは、「設定」画面からいつでも変更できます。

---

## 📱 スマホへのインストール（PWA）

スマホのブラウザでアプリのURLを開き、メニューから **「ホーム画面に追加」** を選択すると、アプリとしてインストールされます。

---

## 🛠️ 開発者向け：ローカルでの起動方法

このリポジトリを取得して手元で動かす場合の手順です。

1. **コマンドプロンプトやPowerShellを開きます。**
2. **プロジェクトのディレクトリに移動します。**
3. **ローカルサーバーを起動します。**
   ```bash
   npx http-server -p 8000
   ```
4. ブラウザで `http://localhost:8000` にアクセスします。

> [!NOTE]
> ログイン機能は、リポジトリ管理者が管理する共通のOAuthクライアントIDを使用しています。`http://localhost:8000` 以外のURL（別ポートや別ホスト名）でログインを試す場合は、そのURLをGoogle Cloud Consoleの「承認済みのJavaScript生成元」に追加する必要があります（リポジトリ管理者のみ対応可能です）。
